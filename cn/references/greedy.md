# 贪心

## 识别信号

> **"局部最优选择"能导向"全局最优"，且选择不需要回溯。**

**讲解时必须做的两件事**：
1. **说清贪心策略是什么**（每一步按什么标准选）
2. **论证为什么这个策略正确** —— 用**交换论证**：假设最优解与贪心解在某步不同，把最优解的那步换成贪心的选择，证明不会变差

如果论证不了，多半不能贪心，考虑 DP。

## 区间贪心：三种排序要分清

| 题目 | 排序依据 | 核心操作 |
|---|---|---|
| 435 无重叠区间 | **右端点** | 冲突就丢当前的 |
| 452 引爆气球 | **右端点** | 与435几乎同题（判断符号 `>` vs `>=` 的差别） |
| 56 合并区间 | **左端点** | 冲突就合并、扩展右边界 |
| 253 会议室II | **左端点** + 最小堆 | 堆顶存最早结束时间 |

**口诀：留最多 / 用最少工具 → 按右端点排；合并 / 覆盖 → 按左端点排。**

**435 的关键论证**：按右端点排序后，冲突时丢当前的——因为当前区间右端点更大、占地更多，丢它**严格不劣**。

## 跳跃游戏：隐式 BFS 分层

**45（最少步数）**维护三个量：
- `cur_end`：当前这一跳能到达的**右边界**
- `farthest`：在当前层的所有位置里，**下一跳能到的最远处**
- `jumps`：跳跃次数

遍历到 `n-1`，每步更新 `farthest`；当 `i == cur_end` 时 `jumps += 1; cur_end = farthest`。

**讲解时要点明两件事**：
1. **不需要显式挑落点**——`farthest` 自动记住了当前层的最优落点
2. **本质是隐式 BFS 分层**：`cur_end` 是当前层的右边界，撞到边界就进入下一层

> **能把 BFS 压成贪心，是因为"可达范围连续"**（连续 → 用两个边界变量代替队列，O(1) 空间）。可达范围离散时（如 279/322 每次减一个平方数/硬币）必须用显式 BFS 的队列。

## DP → 贪心的坍缩

**当"某个量的精确值不重要、只有它的极值影响未来"时，DP 可以坍缩成贪心。**

435 无重叠区间：DP 是 O(n²) 会 TLE，贪心 O(n log n)。

**讲解时如果发现某题 DP 会超时，检查是否有这种坍缩。**

---

## 常见踩坑

- 想当然地贪心但策略是错的（322 零钱兑换：`coins=[1,3,4], amount=6`，贪心取大的得 4+1+1=3枚，最优是 3+3=2枚 → **必须 DP**）
- 排序依据选错（该按右端点却按左端点）
- 45 遍历到了 n 而非 n-1，多算一次跳跃
