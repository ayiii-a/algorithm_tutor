# 构造与模拟题

## 识别信号

> **不套用标准算法框架，核心是"观察出数学/几何规律 → 翻译成步骤"。特征：代码很短但规律很难想。**

这类题的应对策略：**直接记住结论**。现场推导往往需要灵感，而记住只要一秒。

---

## 讲解模拟题的四步法

**1. 列清单**：把所有要检查/处理的情况完整列出来
**2. 抽公共逻辑**：找出可复用的子过程，避免重复代码
**3. 理清判断顺序**：哪个先查（顺序错了会漏情况）
**4. 穷举边界**：空输入、单元素、极值、退化情况

> **这类题的评分点是"有没有漏情况"，而非算法优雅。**

## 让数据结构帮你处理边界

**用递归返回空值让"跳过"自动化**（16.08 整数转英文）：
```python
def three_digits(n):
    if n == 0: return []          # 返回空列表，拼接时自动跳过
    if n < 20: return [table[n]]
    if n < 100: return [tens[n//10]] + three_digits(n % 10)
    return [table[n//100], "Hundred"] + three_digits(n % 100)
```
这样 `20` 不会输出 "Twenty Zero"、`100` 不会输出 "One Hundred Zero"，**不用写一堆 `if x != 0`**。

**用列表 + `join` 处理分隔符**，别手动拼字符串（避免多余空格）。

## 经典构造题

**31 下一个排列**（三步，必须记住）：
1. 从右往左找**第一个下降位置** i（`nums[i] < nums[i+1]`）——枢轴
2. 从右往左找**第一个比枢轴大的数**，交换
3. **反转 i 后面**的部分

`i = -1`（全降序=最大排列）时，步骤3反转整个数组 → 自然得到最小排列。
> **心法：高位尽量不动，在最低位做最小的增大。**（05.04 下一个数是它的位运算版）

**汉诺塔**（08.06）—— 递归思维的典范：
```python
def move(n, src, aux, dst):
    if n == 0: return
    move(n-1, src, dst, aux)      # 上面 n-1 个：src → aux
    dst.append(src.pop())          # 最大的：src → dst
    move(n-1, aux, src, dst)      # 那 n-1 个：aux → dst
```
> **递归的核心心态：不要试图在脑中展开所有层次（会爆炸）。只需 ① 定义清楚如何分解成同类的更小问题 ② 写好递归基。然后信任递归。**
注意三根柱子的**角色轮换**（参数顺序）。

## 几何题的两个心法

**① 用向量/参数方程，不用斜率**
斜率 `k = Δy/Δx` 有除零问题（垂直线）。参数方程和叉积全程只用加减乘。

**② 叉积是 2D 几何的瑞士军刀**
`cross(a, b) = a.x * b.y - a.y * b.x`
- `= 0` → 两向量共线（平行）
- `> 0 / < 0` → 判断转向（左转/右转）
- `|cross|` → 平行四边形面积

用途：判平行、线段求交、凸包（Graham扫描）、判点在三角形内。
