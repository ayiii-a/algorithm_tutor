# 我的错题本

> **这个文件由你自己维护，初始是空的。** 每次做错就加一条，Mode B 分析代码前会先查这里——重复犯的错会被标记成"又是这个"，而不是从头再讲一遍。
>
> 犯过一次的错和犯过三次的错，是两个不同性质的问题。这个文件的作用就是让这个区别显出来。

## 怎么记

每条三行。重点是让**模式**可被检索，不是把来龙去脉写全。

```markdown
### <这个坑的简短名字>
- **出现在**：哪些题上栽过
- **错误写法**：当时实际写了什么
- **正确写法**：一句话说清该怎么写
```

## 它会被怎么用

Mode B 给出结论之前会扫这个文件。如果你的 bug 命中了某条记录，会在开头直接点出来：

> 这和你记的《二分模板混搭》是同一个坑，第三次了。下面重点说为什么这个模式会反复出现。

然后把篇幅花在**为什么这个模式反复出现**上，而不是重讲一遍机制。
