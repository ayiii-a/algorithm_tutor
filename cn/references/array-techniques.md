# 数组与字符串技巧

## 前缀和

**识别信号**：频繁查询"区间和"，或求"和为 k 的连续子段"。

**核心等式**：`区间[i,j]的和 = prefix[j+1] - prefix[i]`

**"和为 k 的子数组个数"**（560）用**前缀和 + 哈希表**：
```python
count = {0: 1}          # 前缀和0出现1次（处理"从头开始"的子段）
for x in nums:
    cur += x
    ans += count.get(cur - k, 0)     # 查：有几个更早的前缀和等于 cur-k
    count[cur] = count.get(cur, 0) + 1
```

**可以迁移到树上**（437/04.12）：把"从根到当前节点的和"当前缀和。⚠️ **递归返回前要 `count[cur] -= 1`**（回溯移除，前缀和只对当前分支的子孙有效）。

**动态版**：需要边插入边查前缀和 → 用**树状数组 BIT**（见 design.md）。

## 双指针

| 模式 | 场景 |
|---|---|
| **对撞指针**（左右向中间） | 有序数组两数之和、盛水容器、反转 |
| **快慢指针** | 原地删除/移动元素、链表判环 |
| **滑动窗口** | 连续子段（见 sliding-window.md） |
| **归并双指针** | 合并两个有序序列 |

### 从后往前填充

> **原地修改时，如果新数据会覆盖还没读的数据，就从后往前填。** 因为写入位置永远在读取位置的右边（那片区域是空缓冲或已处理区）。

例：88/10.01 合并有序数组（三指针 `i=m-1, j=n-1, k=m+n-1`，大的先放最后）、01.03 URL化、977 有序数组的平方。

**判断标准：让写入指针永远"追不上"读取指针。**

## 哈希分组：为等价类设计"规范形式"

> **要把"某种意义下等价"的对象分组，关键是给每个等价类设计一个唯一的规范形式(canonical form)当哈希 key。**

| 题 | 等价关系 | 规范形式 |
|---|---|---|
| 49/10.02 变位词组 | 字母组成相同 | 排序后的字符串 / **26位计数元组**（更快） |
| 205 同构字符串 | 字符映射同构 | 首次出现位置序列 |
| 249 移位字符串分组 | 相对移位相同 | 各字符与首字符的差值序列 |
| 572/04.10 判子树 | 树结构相同 | **序列化字符串**（注意分隔符三坑） |

⚠️ Python 字典 key 必须**可哈希**：用 `tuple(count)` 不能用 `list`。

## 抵消思想

**摩尔投票**（169/17.10 多数元素）：找出现次数 > n/2 的元素，**O(n) 时间 O(1) 空间**。

```python
candidate, count = None, 0
for x in nums:
    if count == 0: candidate, count = x, 1
    elif x == candidate: count += 1
    else: count -= 1
```

**原理**：多数元素的数量超过其他所有元素之和，两两抵消后必有剩余。
⚠️ **如果题目不保证多数元素存在，必须第二遍遍历验证** `count(candidate) * 2 > n`。

进阶 229（> n/3）用**两个候选者**。同族：136 用异或抵消。

## 矩阵技巧

**旋转**（48/01.07）：**顺时针90° = 转置(沿主对角线) + 每行反转**
- 逆时针90° = 转置 + 上下翻转
- 180° = 上下翻转 + 左右翻转
- 原理：**两次反射 = 一次旋转**

**阶梯搜索**（240/10.09）：行列均升序时，**从右上角**开始——大了向左（值变小）、小了向下（值变大），O(m+n)。
> **起点选择的关键：两个移动方向的值变化必须相反**才能判定方向。左上/右下角同增同减，不行。

⚠️ 对比 74（全局升序，行首 > 上一行末）：可以直接**当一维数组二分** O(log mn)。两题的矩阵性质不同，别搞混。

**先记录后修改**（73/01.08 零矩阵）：
> **当"修改数据"会影响"后续的判断依据"时，必须拆成两趟：第一趟只读只记录，第二趟统一修改。**

⚠️ 零矩阵**不是传播问题**——清零产生的新0不该再触发清零，所以不能用 DFS。
O(1) 空间技巧：**用第一行第一列当标记位**（先单独记录第一行列本身是否含0，最后才处理它们）。

## 值当下标

**值域是合法下标时**，数组可以看成隐式链表 `i → nums[i]`：
- 287 寻找重复数：重复值 = 环入口 → **Floyd 判圈**（142 的数组版）
- 41 缺失的第一个正数、442 数组中重复的数据：**原地标记**（把 `nums[|x|-1]` 变负）

**键值有界 → 用键值当下标建桶**：347 前K高频（用频率当下标建桶，O(n) 代替排序）、计数排序。

## Top K

| 场景 | 用 |
|---|---|
| 求前 k 个 / 数据流 / 在线 | **堆**（大小 k 的最小堆，堆顶=第k大）O(n log k) |
| 求第 k 个 / 一次性 / 要 O(n) | **快速选择**（分区后只递归一边） |

⚠️ **快速选择遇大量重复元素会退化 O(n²)** → 用**三路分区**（荷兰国旗 75）：分 `<pivot / ==pivot / >pivot`，等值段一次排除。
