# 回溯

## 心跳骨架

```
def backtrack(路径, 选择列表):
    if 满足结束条件:
        结果.append(路径的快照)     # path[:] 或 ''.join(path)
        return
    for 选择 in 选择列表:
        做选择            # 修改路径和状态
        backtrack(...)    # 进入下一层
        撤销选择          # 恢复路径和状态 ← 灵魂
```

**选择改了几个状态，撤销就要对称还原几个。**（N皇后改了 board + 3个set，就要还原4个）

---

## 讲解时必须确定的四件事

### 1. 这是排列还是组合

| | 控制选择空间 | 收集时机 |
|---|---|---|
| **排列**（顺序有意义） | `used` 数组，每层从 0 开始 | 收集**叶子**（`len(path)==n`） |
| **组合/子集**（顺序无意义） | `start` 指针，`for i in range(start, n)` | 子集收集**所有节点**（append 放函数开头，无 if 拦截） |

### 2. 递归传什么参数

- `backtrack(i+1)`：每个元素**最多用一次**
- `backtrack(i)`：每个元素**可无限重复**（39 组合总和）
- `backtrack(0)` + `used`：排列

**一字之差决定行为。**

### 3. 要不要去重（元素有重复时）

**统一心法：排序 + 同层跳过重复。**

| 用什么控制 | 去重判据 |
|---|---|
| `start` 指针（组合/子集） | `if i > start and nums[i] == nums[i-1]: continue` |
| `used` 数组（排列） | `if i > 0 and nums[i] == nums[i-1] and not used[i-1]: continue` |

**核心：同层不重复尝试相同值，但允许跨层用多个相同值。**
- `[2]` 和 `[2,2]` 都要保留（跨层）
- 同一位置试两次相同的值要跳过（同层）

**`not used[i-1]` 的含义**：前一个相同元素还没被用 → 说明是同层重复 → 跳过；正在被用 → 是跨层，保留。

### 4. 剪枝条件

剪枝是回溯从"能做对"到"做得快"的分水岭。三种来源：

| 剪枝来源 | 例题 |
|---|---|
| **约束计数**（放 `)` 前检查 `right < left`） | 22 括号生成 |
| **几何冲突**（`row±col` 判对角线） | 51 N皇后 |
| **可行性预判**（剩余元素不够 / 当前值已超目标） | 39、216 |
| **记忆化失败状态**（`failed` 集合记录走不通的位置） | 08.02 迷路机器人 |

⚠️ **记忆化只能用于"求一条路径/求能否"，不能用于"求所有方案"**（会剪掉合法方案）。

## 特殊变体

**分割型**（131 分割回文串、93 复原IP、139/140 单词拆分）
选择不是"选哪个元素"，而是"**当前段切到哪里结束**"。骨架相同，只改"每段的合法性判断"。

**网格回溯**（79 单词搜索）
- 原地标记 `board[i][j] = '#'`，回溯时还原
- 边界/越界/不匹配的判断统一写在**递归入口**，不要在四个方向的调用处各写一遍
- ⚠️ **找所有路径要撤销 visited；找连通性不撤销**（200 岛屿数量）

**动态候选集**（04.09 BST序列）
候选集合随选择变化：选一个节点后，把它从候选移除、把它的孩子加入候选。本质是"树上拓扑序的所有方案"。

## 常见踩坑

- **`path[:]` 快照**（第一大坑）：直接 `append(path)` 存的是引用，回溯清空后全变空。字符串用 `''.join(path)` 天然是快照
- 子集问题把 append 放进了 if 里（应该放函数开头，收集所有节点）
- 去重判据写成 `i > 0` 而非 `i > start` → 把跨层的合法重复也剪掉了
- 撤销时漏还原某个状态
- 需要对标量计数时忘记 `nonlocal`（Python 作用域）
