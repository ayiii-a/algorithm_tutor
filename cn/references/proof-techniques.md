# 证明技巧

用来**论证算法正确**的工具，而不是想办法把它写出来。课程类问题读这个文件：正确性证明、归约、"这条贪心规则凭什么成立"、"证明这个界是紧的"。

复杂度推导本身（主定理、摊还分析、循环不变式）在 `complexity-and-proofs.md`，两个文件配合使用。

---

## 先判断：题目要的是哪一类论证

| 问题形式 | 对应工具 |
|---|---|
| 证明这个算法输出正确/最优 | 归纳法、交换论证，或某个结构性质（割性质、贪心保持领先） |
| 证明它会终止 | 一个严格递减且有下界的度量 |
| 证明这个复杂度界 | 递归式、摊还分析；下界则用对手论证 |
| 证明 X 是 NP-hard | **从**一个已知困难问题归约过来 |
| 说明某个启发式不对 | 一个反例——把它构造出来，不要只是描述 |

**先点出该用哪个工具，教学价值已经完成一半。** 学生通常记得定义，但不知道眼下这个局面该动用哪件武器。

## 归纳法的四种实际形态

### 弱归纳
基础情形，然后 P(n-1) → P(n)。简单递归式够用。

### 强归纳
假设对**所有** k < n 都有 P(k)。当递归拆出的子问题大小不可预知时必须用它——快速排序、切分不均的分治、大多数树算法。

> 归并排序的正确性：假设两次递归调用能正确排序**任意更短的**数组（强归纳），再证明 `merge` 保持有序。弱归纳表达不了这件事——两个半边并不是"n-1"。

### 结构归纳
沿着对象的构造方式归纳，而不是沿着数字。树、表达式、文法的天然形态。

> BST 的中序遍历有序：基础情形是空树；归纳步骤假设两棵子树都成立，再用 BST 不变式证明 `左 ++ [根] ++ 右` 拼接后仍有序。

### 循环不变式 = 对迭代次数归纳
初始化是基础情形，保持是归纳步骤，终止是读出结论的地方。完整模式见 `complexity-and-proofs.md`。

## 贪心的两套标准骨架

### 交换论证
把任意一个最优解一步步换成贪心解，每次交换都不变差。详见 `complexity-and-proofs.md`。

### 贪心保持领先
证明每走完 k 步，贪心的部分解按某个度量都不劣于任何其他解的前 k 步。那么终局它必然最优。

> 区间调度：选完 k 个区间后，贪心的第 k 个区间结束时间不晚于任何合法安排的第 k 个。对 k 归纳。

**什么时候用哪个**：交换论证适合"最优解是个集合，我们替换其中的成员"；保持领先适合"解是按顺序构造出来的，我们比较前缀"。

## 割性质（MST 正确性）

Kruskal 和 Prim 背后共同的那一条引理：

> 对图的任意一个割，如果某条横跨该割的边权重严格最小，那么它属于**每一棵** MST。

**证明的形状（值得复现，它是图上交换论证的范本）**：假设某棵 MST 的 T 不含这条边 e。把 e 加入 T 会形成一个环，而这个环必然通过另一条边 f 第二次横跨该割。因为 w(e) < w(f)，用 e 换掉 f 得到更轻的生成树——与 T 最小矛盾。

- **Kruskal** 把它用在"分隔正被合并的两个连通分量"的那个割上
- **Prim** 把它用在"已生成的树与其余部分之间"的那个割上

**当学生问"Kruskal 为什么正确"，答案是割性质 + 它被用在哪个割上**，而不是把算法流程再走一遍。

## Dijkstra：撑起证明的那个不变式

> 当一个顶点被从优先队列中取出时，它记录的距离已经是最终且正确的。

对取出顺序做归纳。反证的那一步：若 u 被取出时距离还不是最终的，那么真正更短的那条路径必然在某个顶点 y 处离开已确定集合，而 y 的距离更小——那样先被取出的应该是 y 而不是 u。

**注意非负性用在了哪里**：正是"路径剩余部分只会增加权重"这一步。这恰好解释了负权边为什么会破坏 Dijkstra，而且把这个前提钉在了真正需要它的那行论证上。**关于一个证明，最有用的往往就是指出每个假设究竟在哪一步被消耗掉。**

## 归约（NP-hard）

要证明 X 是 NP-hard，把一个**已知**困难问题归约**到** X：`已知 ≤ₚ X`。

需要证三件事，而第三件最常被漏掉：

1. 变换在**多项式时间**内完成
2. 已知问题的 yes 实例映射到 X 的 yes 实例
3. **X 的 yes 实例能映射回已知问题的 yes 实例**——反方向

> **方向搞反是头号错误。** "X 很难，所以我把 X 归约到 3-SAT"什么都没证明——那只说明 X 不比 3-SAT 更难。已知困难的那个问题永远是**起点**，不是终点。

要证明 X 属于 NP，给出一个能在多项式时间内验证的证书。NP-完全 = 属于 NP **且** NP-hard，证明 NP-完全性两边都要做。

## 终止性

找一个每步严格递减、且不能无限递减的量——一个自然数，或任何良基序。

- 欧几里得算法：第二个参数严格递减且非负
- 按秩合并的并查集：连通分量数递减
- `left < right` 且两端向内移动的循环：`right - left` 递减

**学生的递归停不下来时，缺的几乎总是这个度量**——所以有用的诊断问题是：*这里什么东西在严格变小？*

## 让证明失效的五个漏洞

学生的证明"感觉不对"但说不出哪不对时，先查这五处：

| 漏洞 | 长什么样 |
|---|---|
| **归纳假设太弱** | 归纳步骤需要一个比正在归纳的命题更强的结论。解法是把命题**加强**——反直觉的是，证明更强的命题往往更容易 |
| **基础情形没对上实际** | 证了 n=1，但递归实际触底在 n=0 或 n=2 |
| **等价性只证了一个方向** | 尤其常见于归约，以及"当且仅当"的命题 |
| **假设了要证的结论** | "贪心选择是最优的，所以贪心算法最优" |
| **"显然"承担了真正的工作** | 这个词标记的正是被跳过的那一步。它一出现，那就是该展开的地方 |

**批改学生的证明时，先查这五条。** 这个层次上崩掉的证明，几乎全都是其中之一。
