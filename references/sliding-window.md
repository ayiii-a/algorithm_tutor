# 滑动窗口

## 识别信号

> **"连续子段满足某条件"的最优问题**（最长/最短/计数）。

关键词：**连续**子数组/子串 + 最长/最短/恰好。

---

## 模板

```python
left = 0
for right in range(n):
    加入 nums[right] 到窗口

    while 窗口不满足条件:
        移除 nums[left]
        left += 1

    更新答案(right - left + 1)
```

**讲解时必须确定三件事**：
1. **窗口内维护什么状态**（计数器 / 哈希表 / 某个和）
2. **什么时候收缩左边界**（`while` 的条件）
3. **答案在哪一步更新**（收缩后更新求最长；收缩前更新求最短）

⚠️ **求最长和求最短，更新答案的位置不同**：
- **最长**：收缩到合法后更新（窗口一直保持合法）
- **最短**：一旦合法就更新，然后继续收缩试更小的

---

## 题目地图

| 题 | 窗口内的条件 |
|---|---|
| 3 无重复字符最长子串 | 无重复字符（哈希表记位置） |
| 209 长度最小子数组 | 和 ≥ target（求最短） |
| 76 最小覆盖子串 | 包含所有目标字符（求最短，hard） |
| **05.03 翻转数位** | 最多一个 0 |
| 1004 最大连续1的个数III | 最多 k 个 0（05.03 的推广） |
| 424 替换后最长重复字符 | 窗口内非最多字符的数量 ≤ k |
| 438 找所有字母异位词 | 固定长度窗口 + 字符计数匹配 |

## 变体：固定长度窗口

如果窗口大小固定，不需要 `while` 收缩，直接：
```python
for right in range(n):
    加入 nums[right]
    if right >= k:
        移除 nums[right - k]
    if right >= k - 1:
        更新答案
```

---

## 常见踩坑

- 答案更新的位置放错（最长/最短搞混）
- 收缩时忘记同步更新窗口状态（哈希表计数、和）
- 窗口大小算成 `right - left`（应该是 `right - left + 1`）
- 用 `if` 而非 `while` 收缩（可能一次要收缩多格）
