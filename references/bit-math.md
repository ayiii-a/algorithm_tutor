# 位运算与数学

## 位运算：讲解时先确定用哪个工具

| 需求 | 工具 |
|---|---|
| 数 1 的个数 | `n &= n-1` 循环（次数=1的个数） |
| 判断 2 的幂 | `n & (n-1) == 0` |
| 取最低位的 1 | `n & (-n)` |
| 找"哪些位不同" | **异或** `a ^ b` |
| 找只出现一次的数 | **异或消消乐**（`a^a=0`） |
| 判重/集合（元素≤64种） | **位掩码当集合** |
| 修改某几位 | **清位-移位-合并** |
| 对"每隔k位"批量操作 | **掩码分离**（`0x55555555` 等） |
| 乘除/幂 | **二进制分解 / 倍增** |

---

## 异或的三个性质

- `a ^ a = 0`（自己抵消 → 找单独元素：136、268）
- `a ^ 0 = a`
- **`a ^ b` 的每个 1 标记"两数在该位不同"** → **汉明距离 = popcount(a^b)**（461、05.06）

⚠️ **异或结果是"哪些位不同"的掩码，不是"不同的位数"** —— 要数 1 的个数才是答案。（1318 就栽在这）

---

## 位掩码当集合

元素种类 ≤ 64 时，用一个整数的二进制位表示集合：

| 操作 | 写法 |
|---|---|
| 查询元素 i 在不在 | `mask & (1 << i)` |
| 添加元素 i | `mask \|= (1 << i)` |
| 删除元素 i | `mask &= ~(1 << i)` |
| 翻转元素 i | `mask ^= (1 << i)` |

应用：01.01 判定字符唯一、78 子集的位掩码枚举、**状压 DP**、N皇后优化。

---

## 修改整数某几位：清位-移位-合并

```python
ones = ((1 << (j-i+1)) - 1) << i     # 造出 i~j 位为 1
num &= ~ones                          # ① 清位
num |= (M << i)                       # ② 移位 ③ 合并
```

**造掩码的核心技巧**：`(1 << k) - 1` 得到 k 个连续的 1。需要"中间0两边1"就取反。

---

## 掩码分离 + 批量移位

对"每隔 k 位"的所有位统一操作时，用掩码一次筛出、整体移位、再合并：

```python
# 交换奇偶位
return ((num & 0x55555555) << 1) | ((num & 0xAAAAAAAA) >> 1)
```

**经典常量**：`0x55555555`(偶位)、`0xAAAAAAAA`(奇位)、`0x33333333`(每2位)、`0x0F0F0F0F`(每4位)。
分离出的两部分移位后位置互补，`|` 合并不会冲突。这是分治式位运算（并行 popcount、190 颠倒二进制位）的基础。

## 二进制分解 / 倍增

```python
while B:
    if B & 1: result += A       # 当前位是1，累加
    A <<= 1                      # A 翻倍
    B >>= 1                      # B 减半
```

`A × B = Σ(A << i)`（对 B 中为 1 的位 i）。O(log B)。

**同构于快速幂**（50）：把 `+= A, A <<= 1` 换成 `*= x, x *= x` 即可。CPU 硬件乘法就是这个原理。

⚠️ 如果题目**禁用位运算**（16.09），用 `acc += acc` 代替 `acc <<= 1`，思想完全一样。

## ⚠️⚠️ Python 位运算的两大坑

Python 整数是**任意精度**，涉及"固定位数整数"时必须手动处理两端：

| 场景 | 问题 | 解法 |
|---|---|---|
| **输入可能是负数** | 负数补码有"无限高位1"，`>>` 永远补 1，会死循环或逻辑错乱 | `num &= 0xFFFFFFFF` **截断** |
| **输出要求有符号** | `0xFFFFFFFF` 在 Python 里是正数，不是 -1 | `v - 2**32 if v >= 2**31 else v` **转有符号** |

**只要题目说"32位整数"，就条件反射地检查这两点。** C++/Java 里 int 天然 32 位，没这个问题。

## 数学题的心法

> **别硬算，找一个等价的、更容易算的表述。**

**16.05 阶乘尾数**的推导链是典范：
尾零个数 → 因子10的个数 → `min(因子2, 因子5)` → **5 比 2 稀缺，所以就是因子5的个数** → 分层统计 `⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + ...`

**勒让德公式**：`n!` 中质数 p 的幂次 = `Σ⌊n/pⁱ⌋`。每一项统计"额外的那一个"。

**其他有用的数学结论**：
- 拉格朗日四平方和：任何正整数都能表示为**至多4个**完全平方数之和（279 的答案永远 ∈ {1,2,3,4}）
- 卡特兰数：合法括号串数、不同BST数、出栈序列数
- 鸽巢原理：n+1 个数放进 n 个抽屉必有重复（287）

## 进制转换

- **整数转 k 进制**：除 k 取余（低位→高位）
- **小数转 k 进制**：乘 k 取整（高位→低位），可能无限循环 → 需要位数上限判 ERROR

> 这解释了**为什么 0.1 在计算机里不精确**：0.1 转二进制是无限循环，double 只能存近似值 → `0.1 + 0.2 != 0.3`。
